# Personal webpage — course example

A simple personal webpage with a dark green theme, a “Hi, I'm Serge” greeting, an About me section, and three example items for sale.

## Open locally

1. Download or clone this repository.
2. Open `index.html` in your web browser.
3. After editing the file, save it and refresh the browser to see your changes.

No installation, build step, or server is required.

## Customize

Everything is in `index.html`: the page content, embedded CSS, and SVG illustrations.

- Replace the remaining `Your Name` placeholders in the browser title, navigation, and footer.
- Write your introduction and About me text.
- Update the example listings, prices, and illustrations.
- Replace the contact placeholder with your preferred contact details or link.
- Adjust the colors in the `<style>` section. The main theme colors are defined in `:root`.

## Features

- Responsive layout for desktop and mobile screens.
- Dark background with light text and green accents.
- Navigation links to the About me, For sale, and Contact sections.
- Self-contained HTML with no external dependencies.

## Demo content

The products, prices, biography prompts, and contact details are illustrative placeholders. The page has no checkout, contact form, or backend. Replace the demo content before using it as a real personal or sales page.
